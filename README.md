# El mapa y el monte · Pequeña historia (Opción B)

Escenario multiagente con el Comandante Fontana y el Cacique Taigoyé que cuenta una historia breve:
Fontana llega en 1879 con un mapa sin nombres, y Taigoyé le enseña palabras qom (Nala', Ca'agoxoic, Mapic, Amap) y le explica que el monte ya tenía quien lo cuidara.
Instructivo N.° 42, Paso 2, Opción B · IA al Colorado · Prof. Ariel Cóceres.

## Cómo grabar el capítulo 16:9
1. Publicá `index.html` en GitHub Pages (pasos abajo) y abrilo en Chrome o Edge desde una computadora.
2. Abrí «Guion y cámaras» → «Guion escrito». La historia ya está cargada.
3. En «Voces» elegí:
   - **Las voces de ElevenLabs de cada personaje**: suenan como sus agentes y gastan créditos. Hay que pegar la clave de API de ElevenLabs (ElevenLabs → Developers → API Keys). No la compartas.
   - **Voz del dispositivo**: gratis y sin internet, para practicar.
4. Tocá **Reproducir** para ensayar y **Grabar video** para bajar el capítulo en 1920×1080.

## Cómo publicarlo en GitHub Pages
1. En tu cuenta `cuentaalumnos`, creá un repositorio público (por ejemplo `el-mapa-y-el-monte`).
2. *Add file → Upload files* y subí `index.html`.
3. *Settings → Pages → Branch: main → Save*. A los pocos minutos queda en `https://cuentaalumnos.github.io/el-mapa-y-el-monte/`.
